# 正式文档生成（GB/T 8567 项目级）

## 目的

扫描项目代码和已有文档，自动生成 7 种 GB/T 8567 正式交付文档，输出到 `docs/`（不分功能，项目级统一产出）。

### 7 种文档

| # | 文档 | 主要信息源 |
|---|------|-----------|
| 1 | 概要设计说明书 | README + PRD + DESIGN + 代码结构 |
| 2 | 详细设计说明书 | 代码（路由/模型/组件）+ decisions |
| 3 | 数据库设计文档 | 代码（ORM 模型/migration）+ SQLAlchemy 模型 |
| 4 | 接口文档 | 代码（Flask 路由/blueprint） |
| 5 | 验收测试报告 | README 功能状态 + 手工验证记录 |
| 6 | 部署运维手册 | docker-compose.yml + Dockerfile + nginx.conf |
| 7 | 用户操作手册 | 前端页面结构 + 路由 + README 功能描述 |

## 触发

用户说"生成正式文档"、"生成交付文档"、"generate deliverables"、"生成 GB/T 8567 文档"时触发。

## 与旧版的关键区别

- **旧版（已废弃）**：依赖 `.specflow/specs/active/<feature>/SPEC.md` + `ACCEPTANCE.md`，按功能逐个生成
- **新版（当前）**：直接从项目代码 + `.specflow/docs/*.md` + `README.md` + `docker-compose.yml` 提取信息，项目一次性生成所有 7 种文档

---

## 流程

### 第 1 步：信息采集（并行扫描）

同时扫描以下信息源：

```
代码层：
  - backend/app/ — 所有 .py 文件（模型、路由、服务）
  - frontend/src/ — 所有 .tsx/.ts 文件（页面、组件、路由）
  - docker-compose.yml + backend/Dockerfile + frontend/Dockerfile
  - nginx/nginx.conf
  - backend/requirements.txt + frontend/package.json

文档层：
  - README.md（项目概述、技术栈、功能模块表、部署说明）
  - .specflow/docs/PRD.md（产品需求、功能清单）
  - .specflow/docs/NFR.md（非功能需求）
  - .specflow/docs/DESIGN.md（设计基线）
  - .specflow/memory/decisions.md（架构决策）
```

### 第 2 步：逐文档填充

按 7 个模板逐个填充。规则：
- 能从信息源推断的 → 填入具体内容
- 无法推断的 → 标注 `[待补充]`
- 模板所有章节必须出现，禁止跳过
- 已有人工填写内容（非 `[待补充]`）→ 只更新自动推断部分，不覆盖人工内容

### 第 3 步：输出

写入 `docs/`，文件名如下：

| 文件 | 路径 |
|------|------|
| 概要设计说明书 | `docs/01_概要设计说明书.md` |
| 详细设计说明书 | `docs/02_详细设计说明书.md` |
| 数据库设计文档 | `docs/03_数据库设计文档.md` |
| 接口文档 | `docs/04_接口文档.md` |
| 验收测试报告 | `docs/05_验收测试报告.md` |
| 部署运维手册 | `docs/06_部署运维手册.md` |
| 用户操作手册 | `docs/07_用户操作手册.md` |

每份文档末尾追加：
```
> 本文档由 generate-deliverables 自动生成。生成时间：YYYY-MM-DD HH:MM
> 缺失信息已标注 [待补充]，请人工审核后补全。
```

### 第 4 步：生成摘要

生成完毕后，输出摘要表格：

| 文档 | 章节完整性 | 待补充项 | 状态 |
|------|:--:|:--:|:--:|
| 概要设计说明书 | 7/7 | 3 | ✅ |
| ... | ... | ... | ... |

---

## 硬门禁

- **不编造**：无信息源支撑 → 必须标注 `[待补充]`
- **不跳章**：模板全部章节必须出现
- **不覆盖人工**：已有非 `[待补充]` 的人工内容 → 只更新自动推断部分
- **中文输出**：所有填充使用简体中文
- **项目级**：7 份文档覆盖整个项目，不按功能拆分
