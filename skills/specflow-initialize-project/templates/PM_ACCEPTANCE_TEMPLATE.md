# <功能名称> — 验收标准（PM 版）

> 本文件面向产品经理，用业务语言描述验收条件。不涉及技术验证方式。
> 技术验收清单见 `.specflow/specs/active/<feature-name>/ACCEPTANCE.md`

## 功能验收（从用户视角）
- [ ] A1. <作为 [用户角色]，我可以 [完成某个操作]，预期看到 [具体结果]>
- [ ] A2. <作为 [用户角色]，在 [异常场景] 下，我看到 [合理的错误提示/兜底状态]>

## 体验验收
- [ ] U1. 界面文案清晰，用户能看懂每一步要做什么
- [ ] U2. 操作后有反馈（加载中/成功/失败），用户知道当前状态
- [ ] U3. 错误提示用通俗中文，说清楚"哪里错了、怎么处理"
- [ ] U4. 不会出现看不懂的英文或技术代码

## 数据验收
- [ ] D1. 列表/详情页显示的数据与业务规则一致
- [ ] D2. 数值计算结果正确（金额/数量/百分比等）
- [ ] D3. 空数据时有合理的空状态提示

## 兼容性验收
- [ ] C1. 在主流浏览器 / 移动设备上功能可用
- [ ] C2. 页面打开速度可接受（无明显卡顿）
- [ ] C3. 新功能不影响已有功能的正常使用
